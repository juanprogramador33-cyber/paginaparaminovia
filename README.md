# Página Web de Cumpleaños para tu Novia 🎂💌

Página web romántica y personalizable con galería de fotos, línea de tiempo, carta interactiva en sobre, razones por las que la amas, vales de regalo canjeables y sección de canción especial.

Funciona directamente abriendo `index.html` en cualquier navegador (no requiere instalar dependencias ni servidores complejos).

## Cómo personalizarla

### Opción 1: Editando `config.js` y la carpeta `fotos/` (Recomendado para publicar)
1. Abre el archivo `config.js` con cualquier editor de texto.
2. Reemplaza todos los textos entre corchetes `[ASÍ]` (`[NOMBRE DE ELLA]`, `[TU NOMBRE]`, `[APODO CARIÑOSO]`, etc.).
3. Copia tus fotos dentro de la carpeta `fotos/` usando los nombres indicados en `fotos/LEEME.txt` (o cambia los nombres en `config.js` para agregar todas las fotos que quieras).

### Opción 2: Vista previa rápida desde el navegador
1. Abre `index.html` en tu navegador (Chrome, Edge, etc.).
2. Haz clic en **"Personalizar nombres y probar fotos"** al final de la página.
3. Escribe sus nombres, sube fotos desde tu computador para ver cómo quedan al instante y usa **"Descargar config.js"** para guardar los cambios de texto.

## Cómo enviársela como regalo
- **En tu computador / celular:** Comparte la carpeta completa (o abre `index.html` cuando estén juntos).
- **Como enlace web gratis:** Sube la carpeta completa (incluyendo `fotos/` con las imágenes y tu `config.js` editado) a **Netlify Drop** o **GitHub Pages** para obtener un link privado/público que ella pueda abrir desde su celular.
